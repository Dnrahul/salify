## 📖 About Salify

Salify is a privacy-first file compression tool that processes everything locally in your browser. Your files never leave your device, ensuring complete privacy and security. Perfect for compressing images, videos, and PDFs without the need to upload them to any server.

### 🎯 Why Salify?

Most online compression tools upload your files to their servers, raising privacy concerns. Salify takes a different approach:

- ✅ **Zero uploads** - Files stay on your device
- ✅ **Complete privacy** - No data collection
- ✅ **Lightning fast** - No network delays
- ✅ **Offline capable** - Works without internet
- ✅ **100% free** - No hidden costs

## ✨ Features

### Core Features
- 🔒 **100% Private Processing** - All compression happens locally on your device
- 📦 **Multiple File Types** - Support for MP4, MOV, JPG, PNG, and PDF files
- ⚡ **Real-time Progress** - Live compression progress tracking
- 💾 **Batch Processing** - Compress multiple files simultaneously
- 📤 **Easy Export** - Download individually or all at once

## 🚀 Quick Start

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Dnrahul/salify.git
   cd salify
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   ```
   Navigate to http://localhost:3000
   ```

### Build for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

## 📱 Usage Guide

### Step 1: Select Files
Click the upload area or drag & drop your files. Supported formats:
- **Images:** JPG, PNG
- **Videos:** MP4, MOV
- **Documents:** PDF

### Step 2: Choose Compression Mode
Select from three compression levels based on your needs:
- **High Quality** - Minimal compression, best for professional use
- **Balanced** - Good compression with maintained quality
- **Max Compression** - Smallest file size, best for storage/sharing

### Step 3: Compress
Click "Start Compression" and watch the magic happen in real-time!

### Step 4: Download & Share
- Download individual files
- Download all files at once
- Share via WhatsApp, Email, or Cloud storage

## 🔐 Privacy & Security

### Our Privacy Commitment

- ✅ **No Server Uploads** - Files are never sent to any server
- ✅ **No Data Collection** - We don't track or store any user data
- ✅ **No Analytics** - Your usage remains completely private
- ✅ **No Cookies** - No tracking cookies or third-party scripts
- ✅ **Open Source** - Complete transparency, audit the code yourself

### How It Works

1. You select files from your device
2. Files are loaded into browser memory
3. Compression happens using JavaScript Canvas API
4. Compressed files are created in your browser
5. You download the results
6. All data is cleared from memory

**Your files never leave your device at any point!**

## ❓ FAQ

**Q: Is my data really safe?**  
A: Yes! All compression happens in your browser using JavaScript. Your files never leave your device.

**Q: Do I need to install anything?**  
A: No! It's a web app that runs entirely in your browser.

**Q: Does it work offline?**  
A: Yes, after the first load, the app can work offline.

**Q: What's the maximum file size?**  
A: Limited only by your device's available memory. Most modern devices can handle several GB.

**Q: Is it really free?**  
A: Yes, completely free and open-source. No hidden costs or subscriptions.

**Q: Can I use it for sensitive documents?**  
A: Absolutely! Since everything is local, it's perfect for sensitive files.
